HSK WORD BANK — TONE LISTENING TOOLS
=====================================

WHAT THIS IS
------------
8,564 words (HSK 2000 list) with real native-speaker audio recordings,
covering every syllable-count from 1 to 5 characters:

    1-syllable words:  1,734
    2-syllable words:  6,351
    3-syllable words:    292
    4-syllable words:    185
    5-syllable words:      2

This is a much bigger companion to the Sinosplice-based tools (practice.html /
assessment.html) you already have. It is NOT a replacement — those tools stay
curated around specific tone-sandhi teaching points (很/挺/不 + adjectives);
this bank is for broad, high-volume tone-perception practice across real
vocabulary.

HOW TO USE IT
-------------
Unzip this whole folder and keep hsk-practice.html, hsk-assessment.html,
hsk_data.js, and the audio/ folder together in the same place — the pages
load audio and data from relative paths, so they must stay side by side.

Then either:
  a) Double-click hsk-practice.html or hsk-assessment.html to open directly
     in a browser (works offline, no server needed), or
  b) Upload the whole folder to GitHub Pages (or similar static hosting) the
     same way you've hosted your other stroke-order tools, so students can
     reach it from a URL instead of a download.

Google Sites cannot host the audio/ folder structure directly — if you want
this on Sites, GitHub Pages + an embedded link/iframe is the more reliable
route, consistent with what you've already found for your other tools.

WORD SELECTION
--------------
Both tools let you filter by word length (1-syllable / 2-syllable / 3+
syllable / all). Meanings and pinyin come from CC-CEDICT, matched
automatically — 32 entries out of 8,596 in the original list were grammar
pattern templates (e.g. "not X unless Y") rather than sound-recordable words,
so those were excluded.

Because this is the full generic HSK 2000 list rather than vocabulary tied to
Go Far With Chinese or Integrated Chinese, some words will be above or below
what your students have currently learned. The syllable-length filter helps
narrow scope, but if you want it scoped precisely to what you teach, the
next step would be cross-referencing against your Vocab_Masterlist.xlsx —
happy to build that filtered version if useful.
